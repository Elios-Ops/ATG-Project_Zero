# Event Horizon integration status — BLOCKED

The supplied Meshy models are each a single opaque textured mesh, not separated editable glass/display/structure components. Their black-hole imagery is baked into the supplied albedo texture and is static. The preserved shaders use Project 0 shared `p0Time`; existing Lot 82 shader coordinates still refer to its former narrower display.

No original shader or live exterior was replaced. Shader copies in shader-sources are preservation references, not a configured production package. A true separate thin display immediately behind glass requires splitting/rebuilding the facade and creating glass apertures; inserting a hidden panel into an opaque Meshy facade would not produce visible animation.

Required production zone is Y=35–57m, height 22m; Lot 82 inward face is west (-X), Lot 106 east (+X), property gap is 4m. Uniform fitting preserves proportions but does not necessarily fill the authorized height. Do not publish these candidates as a completed Event Horizon installation.

## Visual quality gate

Actual Blender comparisons show that aggressive Collapse reduction breaks RAMPAGE into visible shards/holes at LOD2 and strongly degrades framework at LOD1. Passing triangle/material/byte limits is insufficient. These results are diagnostic candidates, not accepted optimized production assets. Stop rather than deploying them. Use explicit closed silhouette retopology, UV transfer and high-to-low bake for distant levels.
